# ACPI sources

Only tables that cannot be fetched or compiled from upstream live here.

- `SSDT-AWAC.aml` — prebuilt, generated by
  [SSDTTime](https://github.com/corpnewt/SSDTTime) for this board.
- `SSDT-EC-USBX.aml` — prebuilt. Dortania's comprehensive table (OEM ID `DRTNIA`, 7341
  bytes), which covers every EC/USBX device path. OpenCorePkg's same-named sample is a
  306-byte template and is **not** a substitute.

`SSDT-PLUG-ALT` is not here: it is compiled straight out of the OpenCore package via
`oc_ssdt(SAMPLES SSDT-PLUG-ALT)`, since it is an unmodified upstream file.

Machine-generated tables have no maintained `.dsl`, which is what `oc_acpi()` is for.
Anything you actually edit belongs in `oc_ssdt()` as a path.
